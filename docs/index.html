Bitcoin Wallet Core

Generates a real BIP39/BIP84 mainnet Bitcoin wallet, entirely in this tab.

No server, no analytics. Generation runs entirely in your browser with the same createWallet() function this repo ships and tests — open your Network tab, nothing fires when you click the button. The one exception is the optional "Verify" button below the result, which asks a public block explorer's API whether the address is real.

Source: github.com/frankie-muller/bitcoin-wallet-core — this page is demo-web/main.ts, bundled as-is into bundle.js.
